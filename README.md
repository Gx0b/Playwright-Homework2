# Playwright Homework 2

Automated functional testing project for the SauceDemo web application using Playwright and JavaScript.

## Requirements

- Node.js 18 or later
- npm

## Installation

```bash
git clone https://github.com/Gx0b/Playwright-Homework2.git
cd Playwright-Homework2
npm install
npx playwright install chromium
```

## Run the Tests

```bash
npx playwright test
```

## View the HTML Report

```bash
npx playwright show-report
```

## Test Cases

- TC01 – Login with valid credentials
- TC02 – Reject invalid credentials
- TC03 – Display the Products page
- TC04 – Add a product to the cart
- TC05 – Display the selected product in the cart
- TC06 – Remove the product from the cart

## Test Result

All six automated test cases passed successfully.
